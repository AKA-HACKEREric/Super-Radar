# 📡 Super Radar

A modern Bluetooth & Wi-Fi radar visualization tool built with Python.

Scan nearby BLE devices in real time with an interactive radar interface, device identification, and signal analysis.

# ✨ Features

- 📡 Real-time Bluetooth Low Energy (BLE) scanning
- 📶 Wi-Fi network detection
- 🎯 Interactive radar visualization
- 📍 Live RSSI signal monitoring
- 🏷️ Device brand recognition
- 🔍 BLE Appearance & Service UUID detection
- 🛡️ Basic spoofing detection
- 🔊 Sonar sound effects
- ⚡ Multi-threaded scanning engine
- 🎨 Modern radar-inspired interface

---

# 📦 Requirements

- Python 3.11+
- Windows 10 / 11
- Bluetooth Adapter (BLE Supported)

---

# 📥 Installation

Clone the repository

```bash
git clone https://github.com/AKA-HACKEREric/Super-Radar.git
cd Super-Radar
```

Install dependencies

```bash
pip install bleak pygame playsound pillow
```

(Optional)

```bash
pip install pyinstaller
```

Run the project

```bash
python Super-Radar.py
```
